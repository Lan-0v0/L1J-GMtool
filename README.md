# 龙潭 GM 台

本地网页 GM 台。只监听 `127.0.0.1`，读写 `../服务端/config/sql.properties` 的库 `x8`，向 `Lin.bin`（窗口标题含 `13032701`）粘贴 GM 指令。不改游戏客户端、服务端 jar。

## 启动

1. 若尚未编译：双击 `编译.bat`（用 `天堂\JDK11`）。
2. 双击 `启动GM工具.bat`，浏览器打开本机页面。

## 用法要点

- 顶栏多选角色。点芯片设为**操作者**（正在游戏窗口里玩的号）。
- **移到此人处**：把已选角色送到列表那一行。操作者发 `.跟o 名字`；离线号进待办，下线后写对方**存档坐标**。
- 地图点击发 `.传送o x y 4`，飞的是操作者自己。
- 物品 `.do` 进操作者背包，`.给予o` 进仓库。不要给在线角色插 `character_items`。
- 新建物品/NPC 是写库，**重启游戏服**后才进内存。
- NPC「出现在操作者脚底」发 `.npco 编号`（朝向=操作者当前面向）。

## 安全

- 数据库密码不进网页、不另存。
- 待办谁先离线谁执行，可取消。
- 审计在本目录 `data\audit.log`。
